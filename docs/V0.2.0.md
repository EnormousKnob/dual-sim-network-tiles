# 0.2.0 功能与验收说明

此版本是功能扩展测试版。0.1.4 的两项切换和三星磁贴即时刷新已由用户确认；0.2.0 新增功能尚未在 S24 Ultra / One UI 8.5 上实测。

## 已实现

1. **本地诊断**：诊断页可查看、复制、分享报告，保留最近60条操作，包括设备/固件、Shizuku状态、接口签名、SIM槽位与订阅ID、网络掩码、执行路径、命令输出、耗时和异常。报告不含卡名称、手机号、原始ICCID、SIM匹配摘要或自动化令牌。不会自动上传。
2. **接口兼容探测**：按运行时参数类型匹配已知重载，缓存命中和缺失签名；网络写入兼容3参数及附带调用包名的4参数接口，均不存在才执行系统命令兜底。权限拒绝和明确失败不会被重试掩盖。写入后仍读取确认。IPC超时会标为结果不确定，不自动重试写入；请检查系统设置并重新启动Shizuku。
3. **每卡偏好**：网络磁贴可跟随默认数据卡或固定SIM 1/2；两张卡分别设置保持当前模式、4G优先、5G自动。可选切卡后应用新数据卡偏好，或将非数据卡禁用5G。这些选项默认不启用，仅在通过本应用切卡后应用，不持续覆盖系统设置。
4. **恢复原始设置**：本版首次修改前同步保存当前卡网络设置和默认数据卡；按SIM匹配摘要/订阅ID/槽位校验后恢复。备份保留，恢复失败不删除；它不是出厂默认，也不能还原升级前未保存的历史状态。仅处理当前可匹配的卡，移除或停用卡需重新启用再恢复。全局恢复会暂停自动监控。
5. **快捷方式与自动化**：长按应用图标可选SIM 1、SIM 2、4G优先、5G自动；设置页可固定桌面快捷方式，包括恢复。所有动作指定目标，重复执行不往返切换。普通应用不能无令牌调用快捷Activity。三星模式和日常程序是否展示应用快捷方式取决于系统，仍需实测；不能保证直接兼容所有版本。
6. **新界面**：首页、偏好设置、诊断与帮助三页；卡片式状态、备份/恢复入口，系统/浅色/深色/纯黑主题。保留SIM 1灰底、SIM 2亮底的三星重绘兼容方式。

## 自动化广播

默认关闭，在设置页主动启用后使用。快捷方式和外部广播使用不同的随机令牌，广播令牌可以重置。

```shell
adb shell am broadcast \
  -a com.example.dualsimtiles.SET_NETWORK \
  -n com.example.dualsimtiles/.AutomationReceiver \
  --es operation 4g --ei slot 0 --es token YOUR_PRIVATE_TOKEN
```

- `operation`：`sim1`、`sim2`、`4g`、`5g`、`restore`。
- `slot`：`0`当前默认数据卡、`1`卡1、`2`卡2；仅网络模式操作使用此选项。
- 桌面4G/5G快捷方式操作当前默认数据卡，与网络磁贴的固定目标设置独立。
- 不接受任意掩码、shell命令、隐式模式别名或toggle操作。
- 请求排队过久会过期。等待结果超过8秒时返回未确认；不要盲目重试，应检查系统设置或诊断报告。
- 关闭外部自动化或重置令牌后，旧命令失效。示例中的真实令牌不要提交GitHub或写入公开日志。

## 弱5G信号自动降级（实验性、默认关闭）

实现的是**弱NR信号降级**，不是网速检测或“假满格”检测。

- 用户明确开启并允许通知后，启动可见的前台服务；不需要Root，但需要已授权且运行中的Shizuku。
- 默认在NR RSRP ≤ −110 dBm且连续3次符合条件时，将默认数据卡禁用5G，保留原有LTE及低代网络回退。
- 必须同时满足：两张卡通话状态均已知且空闲、移动数据启用、当前没有使用Wi-Fi、默认卡及网络模式可识别。写入前再次核验通话状态、默认数据卡和原掩码。
- 亮屏约30秒、息屏约90秒采样，均受系统调度影响；读取失败或未知不会当作弱信号，且会打断连续计数。
- NR测量不等于证明已经驻留NR，尤其NSA环境；此功能依据设备上报的NR测量值，不展示虚假的实时5G连接结论。
- 默认冷却10分钟后**试探恢复**降级前保存的模式。禁用5G期间无法持续观测5G是否恢复，因此不是“检测到5G变好后才恢复”。阈值、次数及冷却可在设置页调整。
- 恢复记录先落盘，再进行修改。进程被杀、Shizuku断开或恢复失败时仍保留；重新打开应用可用“恢复自动降级前的设置”处理。
- 如果旧SIM已经移除或停用，首页提供显式放弃本次自动恢复任务的入口，避免恢复记录阻塞后续手动操作；需要用户确认，不修改系统模式，不删除原始设置备份。
- 用户在应用内手动操作会先暂停监控并处理恢复记录，手动选择优先。检测到外部修改掩码时暂停自动策略，避免覆盖外部选择。
- 通知支持“停止并恢复”；无开机自启、后台反复拉起、联网Ping或HTTP测速，无新增INTERNET权限。系统回收后不会强行自动恢复服务，可能保留4G模式，需要打开应用恢复。
- 此功能使用`specialUse`前台服务声明，Google Play发布仍需相应审核，不代表已获得商店许可。

## 真机验收顺序

1. 从0.1.4覆盖安装，先保持所有新自动选项关闭，验证双卡和4G/5G磁贴双向切换及即时刷新。
2. 切换固定SIM目标，检查只改指定卡、不改默认数据卡；测试单卡及停用卡报错。
3. 设置不同每卡预设，启用切卡应用偏好，验证新/旧数据卡的模式及关闭选项后的行为。
4. 对照系统设置记录首次备份，修改后恢复；停用SIM后恢复应保留记录或明确失败。
5. 测试四个桌面快捷方式及固定入口；检查三星日常程序是否提供启动快捷方式入口。
6. 广播关闭、错误令牌、缺令牌、无效operation必须拒绝；正确令牌执行固定动作；重置后旧令牌失效。
7. 在诊断页手动采样信号，先确认NR读数和双卡通话状态可用，再开启实验监控。
8. 验证瞬时弱信号、未知读数、Wi-Fi和任一卡通话不会降级；连续弱信号才动作。
9. 验证冷却后恢复、停止并恢复、手动操作优先、外部修改优先、Shizuku撤权/重启及进程被杀后的恢复记录。
10. 字体放大、旋转、浅/深主题和三键/手势导航的可读性与安全区域。
