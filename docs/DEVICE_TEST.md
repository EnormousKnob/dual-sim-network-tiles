# S24 Ultra / One UI 8.5 验收记录

状态：用户已确认 0.1.4 在三星 Galaxy S24 Ultra / One UI 8.5 上，数据卡切换、4G/5G 切换和磁贴即时刷新可用。其他三星型号、系统版本及品牌未验证。下面的扩展场景仍按各行结果记录，不代表全部通过。

用户反馈：0.1.0 数据卡切换可用；4G/5G 写入接口报 `NoSuchMethodException: setAllowedNetworkTypesForReason/3`。0.1.1 新增系统命令兼容路径，待用户复测双向切换与磁贴同步。

后续反馈：0.1.1 已确认网络切换可用。0.1.2 网络磁贴图标可立即更新，但换卡成功后 SIM 图标未自动刷新。0.1.3 增加主动刷新、跨磁贴状态同步、有限重读和 SIM 图标位图提交，待复测：面板保持展开时 SIM 1→2→1、切换中收起再展开、应用内切换后展开面板、换卡后网络磁贴是否同步。

0.1.3 实测反馈：无改善，只有切换面板后 SIM 图标才更新。0.1.4 改为 SIM 1 INACTIVE / SIM 2 ACTIVE，使选卡变化伴随磁贴显示状态变化；不更改移动数据开关。请复测面板持续展开时双向选卡的数字图案和底色变化。
