# 双卡网络磁贴隐私政策（发布草稿）

本应用在设备本地运行，不收集、上传、出售或共享个人数据，不含广告或分析服务，无账号注册功能。

经用户明确授予 Shizuku 权限后，本应用读取已启用 SIM 的显示名称、槽位、订阅标识、默认数据卡、设备支持的网络类型和允许使用的网络类型，用于显示快捷磁贴及执行用户发起的切换。

自0.2.0起，应用会在本地保存每卡偏好、修改前的网络设置与默认数据卡备份、自动降级恢复记录及最近的操作日志。特权进程在标识可用时读取SIM标识生成单向摘要，用于防止将旧备份恢复到错误的卡；原始ICCID不离开该进程、不持久保存、不上传。日志和诊断报告不包含SIM名称、原始ICCID、匹配摘要、手机号或授权令牌。设备型号、固件版本、订阅ID、槽位和网络掩码可能出现在用户主动复制或分享的诊断报告中，分享对象由用户自行选择。

外部自动化默认关闭。用户开启后，应用在本地保存随机授权令牌，用于校验自动化请求；桌面快捷方式使用独立令牌。令牌可在应用中重置，不用于跟踪用户。应用禁止这些偏好和备份参与云备份及设备迁移。

弱5G信号监控默认关闭，用户主动开启后通过Shizuku读取本机NR信号测量和通话空闲状态，以决定是否临时禁用5G；不读取通话内容或通话记录，不进行联网Ping/HTTP测速，不读取位置。监控运行期间显示常驻通知，用户可停止并尝试恢复原设置。

本应用不会读取手机号、短信、联系人、位置或浏览记录。应用不请求互联网权限。打开 Shizuku 官方帮助页面时会交给外部浏览器，适用该网站及浏览器的隐私政策。

用户可随时在 Shizuku 中撤销授权或停止服务，也可卸载本应用。撤销权限不会自动恢复此前由用户更改的 SIM 或网络设置，可在系统设置中调整。

在撤销权限或卸载前，可先使用应用的恢复入口；恢复需要电话服务可用且授权有效。卸载会删除本地配置和备份，不会自动撤销已写入系统的网络设置。

Shizuku 是独立第三方工具，其权限和数据处理请参阅其官方说明。

发布前由开发者补充真实的开发者名称、联系邮箱和生效日期，并将最终政策发布到公开可访问的网页；此草稿尚不能直接作为已完成的商店隐私链接。
