# 双卡网络磁贴隐私政策（发布草稿）

本应用在设备本地运行，不收集、上传、出售或共享个人数据，不含广告或分析服务，无账号注册功能。

经用户明确授予 Shizuku 权限后，本应用读取已启用 SIM 的显示名称、槽位、订阅标识、默认数据卡、设备支持的网络类型和允许使用的网络类型，用于显示快捷磁贴及执行用户发起的切换。这些信息只在设备内存中处理，不持久保存，不用于识别、跟踪用户。

本应用不会读取手机号、短信、联系人、位置或浏览记录。应用不请求互联网权限。打开 Shizuku 官方帮助页面时会交给外部浏览器，适用该网站及浏览器的隐私政策。

用户可随时在 Shizuku 中撤销授权或停止服务，也可卸载本应用。撤销权限不会自动恢复此前由用户更改的 SIM 或网络设置，可在系统设置中调整。

Shizuku 是独立第三方工具，其权限和数据处理请参阅其官方说明。

发布前由开发者补充真实的开发者名称、联系邮箱和生效日期，并将最终政策发布到公开可访问的网页；此草稿尚不能直接作为已完成的商店隐私链接。
